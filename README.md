# Welcome to DexDock!

DexDock is a lightweight scrcpy-based application which allows you to easily launch a desktop mode via simply connecting a compatible Android Device to your Windows Computer with an appropriate USB cable.

It features h.264, h.265 and avc support as well as custom resolutions and refresh rates 60-120Hz.

This is v1.0.0 so please forgive any current errors, and feel free to report them or suggest any features to my email; thejackiboi@gmail.com!
